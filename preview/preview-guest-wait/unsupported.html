This page cannot boot the sandbox

Firefox is not supported: the sandbox's workers do not start in it.

Open the playground at yurt-playground.pages.dev in Chrome or Edge on a desktop, or in Safari on a Mac, iPhone or iPad. Or run it on your machine: the desktop app and the command line need none of this.

Why this happened

The playground runs a whole Linux sandbox inside the tab, on SharedArrayBuffer-backed Web Workers. Browsers only allow that on a cross-origin isolated page, and this one is not: the server did not send Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Embedder-Policy: require-corp, or the page is embedded somewhere that strips them. Every current browser supports isolation (Safari since iOS 15.2); the static build ships the headers in _headers.
