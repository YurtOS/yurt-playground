This page cannot boot the sandbox

The Yurt playground runs a whole Linux sandbox inside the browser tab on SharedArrayBuffer-backed Web Workers. Browsers only allow that on a cross-origin isolated page, and this one is not: the server did not send Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Embedder-Policy: require-corp, or the page is embedded somewhere that strips them.

Every current browser supports this, phones included (Safari since iOS 15.2). Open the playground from its own address on a server that sends those headers; the static build ships them in _headers.
