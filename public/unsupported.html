This page cannot boot the sandbox

The playground runs a whole Linux sandbox inside the tab, on SharedArrayBuffer-backed Web Workers. Browsers only allow that on a cross-origin isolated page, and this one is not: the server did not send Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Embedder-Policy: require-corp, or the page is embedded somewhere that strips them.

Every current browser supports this, phones included (Safari since iOS 15.2). Open the playground from its own address, or any server that sends those headers; the static build ships them in _headers. The desktop app and the command line need none of this.
