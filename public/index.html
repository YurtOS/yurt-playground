This looks like a phone or tablet. The sandbox needs around a gigabyte of memory and workers that keep running in the background; mobile browsers often allow neither, so the boot may stall or the tab may reload. A desktop browser is the safe choice.

The playground as a Mac app

The same pages, with the sandbox running natively on your Mac: it has network access and boots in seconds.

Download for Apple Silicon or Intel, open the disk image and drag Yurt Playground to Applications.

It is not notarized, so macOS blocks the first open: allow it under System Settings → Privacy & Security → Open Anyway (or run xattr -dr com.apple.quarantine "/Applications/Yurt Playground.app"), then open it again.

The playground as a Linux app

The same pages, with the sandbox running natively on your machine: it has network access and boots in seconds.

Download the package for x86_64 or arm64 (Debian, Ubuntu), then: 

sudo apt install ./Yurt-Playground-*.deb
yurt-playground

It opens in your browser; Ctrl-C stops it.

yurt: sandboxes from the command line, docker-style

run, exec, ps, rm, images, pull, build — with ports, environment and an interactive terminal. Download for Apple Silicon or Intel, then: 

tar -xzf yurt-*.tar.gz && sudo yurt/install.sh
yurt pull playground
yurt run -it playground                    # a shell in the sandbox
yurt run -d --name web -p 8080:8000 playground python3 -m http.server 8000
curl http://127.0.0.1:8080/

Everything the command needs is in the package; the daemon starts itself. yurt --help lists the verbs.

Is this really running in your browser?

No badge can prove it, so here is what a server-backed fake could not survive. Each check takes under a minute in Chrome.

Go offline, keep computing

Open the terminal and wait for ready. Then turn off Wi-Fi, or in DevTools pick Network → Offline. Run another cell.

It still answers. The page shows offline next to its status while you do it.

Watch the tab work

Open Chrome's Task Manager with Shift+Esc (or the Window menu). This tab's memory climbs by hundreds of MB as the sandbox boots, and its CPU spikes when a cell runs.

A thin client stays flat.

See the workers

Visit chrome://inspect/#workers while a page is running. The coordinator and the sandbox's guest Workers are listed with their script URLs, and you can attach a debugger.

In DevTools Network, nothing moves while a cell runs. The page's security policy forbids talking to any other origin.

Check the bytes

The site publishes the SHA-256 of every file the sandbox runs on, the 87 MB guest filesystem included. This button fetches them again and hashes them here, in your browser; the kernel and the image are also checked against the hash their release was published with.

Nothing leaves the page: the kernel, the filesystem and Python all run in this tab. Source, issues and releases: github.com/YurtOS/yurt-playground.
